How it was run

The result is part discipline, part variance breaking our way — getting both finalists was only ~24% likely. The process, not the outcome, is the point.

01

Fundamentals over Elo

Primary lens was a "Six Forces" model, not Elo — Elo is public and already priced into every line, so it carries no edge. Real edges: environment / knockout-DNA and Singapore-Pools-vs-sharp mispricing.

02

A hard value gate

Only bet lines clearing a 1.15× cushion over fair odds. Most candidates never cleared it — and skipping them is the system working, not a missed bet.

03

No chasing, no top-ups

Exposure capped at $100. Three edge/lottery tickets died exactly as priced and we never reloaded to "get it back." Outcome bias is the chaser's trap.

04

Reserve as insurance

$15 was kept as hedge capital for a one-sided final — deployed only if exactly one of our teams reached it. The best-case all-ours final made a hedge pointless, so it stayed unspent.
